# Galaxy Defender
Galaxy Defender es un videojuego desarrollado en Greenfoot utilizando Java. El jugador controla una nave espacial encargada de defender la galaxia de enemigos que aparecen constantemente desde la parte superior de la pantalla. El objetivo principal será destruir la mayor cantidad de enemigos posible para obtener puntos y sobrevivir el mayor tiempo posible sin perder todas las vidas.
El juego contará con controles simples: el jugador podrá mover la nave hacia la izquierda y derecha utilizando el teclado y disparar proyectiles para eliminar enemigos.
Para la implementación del proyecto se utilizarán las clases principales de Greenfoot, como World para crear el escenario principal y Actor para representar los objetos del juego, como la nave, enemigos y disparos. El proyecto incluirá imágenes, efectos de sonido, contador de puntos y sistema de colisiones entre objetos.
El desarrollo se realizará en equipo utilizando GitHub para organizar el código y controlar los avances de cada integrante. Cada miembro tendrá responsabilidades específicas, como programación del jugador, enemigos, interfaz, sonidos y documentación del proyecto.
